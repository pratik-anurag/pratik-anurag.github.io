Architecture Profiling Kit

Arpkit Visualizer

See how sockets, NUMA nodes, shared caches, cores, and threads fit together.

Paste command output or use a sample. No uploads, backend, or analytics.

Paste any combination of lscpu text, lscpu -J, the extended CPU table, and numactl --hardware. Limit: 1 MiB / 8,192 logical CPUs.

Commands to run
LC_ALL=C lscpu
LC_ALL=C lscpu -e=CPU,NODE,SOCKET,CORE,L1d:L1i:L2:L3
LC_ALL=C numactl --hardware

Append MAXMHZ to the extended columns for frequency-group hints on hybrid CPUs. Default text alone cannot identify SMT siblings or exact cache sharing.
