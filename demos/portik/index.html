Run the CLI locally, then paste its JSON output here. Flags precede the port because Portik uses Go's flag parser:

portik who --json 3000
portik explain --json --docker 5432

Review command lines and hostnames before pasting. Input is kept only in memory, never uploaded or saved. This viewer accepts a single Report object, not scan/graph JSON or raw lsof/ss output.

Scope and differences from the CLI

The diagnosis is a JavaScript port of Portik’s deterministic snapshot checks. The native CLI gathers live sockets, process metadata, Docker mappings, and host context. This page does not run those collectors.

Firewall, container/WSL/VM environment, current UID, live port availability, and parent process trees cannot be established here. The privileged-port hint uses the supplied username instead of OS UID. Existing diagnostics in pasted reports are not replayed; supported checks are recomputed. IPv6-only is a heuristic, not proof of the kernel’s dual-stack setting.
