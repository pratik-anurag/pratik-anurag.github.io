What this demo does—and doesn’t do

Ephor's Python agent scans rule patterns in order and reports the first match. This demo shows that first match plus additional findings. The warning is a simulation: this page cannot intercept other apps, detect your active app, block a paste, or clear your system clipboard.

Only a tested subset of upstream Nosey Parker rules is included. JavaScript regex matching differs from Python/Rust. Identifier rules can match non-secret account IDs and public metadata. Credential validity is never checked.
